Measure every muscle's response to every stimulus pulse

Reads raw EMG recordings and produces one table: peak-to-peak and area under curve per muscle per pulse, with the response timing and the window every number came from.

Open the tool in your browser Download it Read the guide
Your recordings never leave your computer.

The browser version runs the analysis inside your own browser, and the downloads run on your machine. There is no server to send anything to, no account, no cookies and no tracking of any kind.

Three ways to run it

  • Windows

    For whole sessions, participants, or the entire study. Reads folders straight off your hard drive, so size stops mattering.

    Download for Windows

  • Mac

    The same tool, as a Mac app. Nothing to install: unzip it and open it.

    Download for Mac

  • In your browser

    For a look at a few recordings, with nothing installed. A browser can hold a few hundred megabytes, which is less than one session here.

    Open the tool

All three run the same code and give the same numbers.
